## Power Categories Defined

**Low Power:** < 33%
- Detection rate for true effect < 1/3
- High risk of Type II error
- Inconclusive evidence even if significant

**Medium Power:** 33-66%
- Moderate detection rate
- Typical for exploratory studies
- Replication recommended

**High Power:** > 66%
- Good detection rate
- Adequate for confirmatory studies
- Cohen's conventional "adequate power" (>80%) threshold nearby

## Data Extraction Details

**P-Value Extraction:**
1. **Directly reported:** 31/47 datasets provided exact p-values in text/tables
2. **Extracted from figures:** 12/47 required digitization from forest plots or p-curve plots
3. **Calculated from test statistics:** 4/47 computed from reported t, F, or χ² values

**Digitization Method:**
- Software: WebPlotDigitizer v4.5 (https://automeris.io/WebPlotDigitizer)
- Calibration: 3-point calibration on each figure
- Verification: All digitized values cross-checked by second coder
- Accuracy: Mean digitization error <0.5% (tested on synthetic plots)

**Power Calculation:**

**Continuous Approximation:**
```python
median_p = np.median(p_values[p_values < 0.05])
power_approx = 1 - (median_p / 0.05)**0.4
```

**Full Method:**
- Implemented per Simonsohn et al. (2014) Appendix A
- Tests against 33% and 90% power benchmarks
- Uses binomial tests on p-value distribution bins
- Iterative refinement if results ambiguous

**Quality Checks:**
1. All calculations independently verified by DRM
2. Random sample (n=10) cross-validated using p-checker web app
3. Discrepancies (n=2) resolved through re-examination of source papers
4. Final dataset reviewed by all authors

## Recommendations Based on Validation

**Use Continuous Approximation When:**
- N ≥ 8 studies
- Exploratory analysis
- General reporting ("power ~65%")
- Speed required

**Use Full Method When:**
- N < 8 studies
- Formal power claims
- Publication requirements
- High precision needed
- Unusual p-curve shapes

**Expected Accuracy:**
- N ≥ 20: Mean absolute error ~3%
- N 10-19: Mean absolute error ~4%
- N 5-9: Mean absolute error ~6%
- N < 5: Use full method only
